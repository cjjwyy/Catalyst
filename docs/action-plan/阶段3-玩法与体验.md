## T3.9 新人引导与文案易读性(新增)

- 优先级: P2 · 预估: 8h · 状态: [ ] 待开始 · 依赖: T3.5(卡面资源化)
- 目标: 让完全没有接触过"催化剂"的新玩家,不看外部文档也能完成第一局、看懂每张牌、理解每种机制。
- 现状: 卡牌说明由 `RuleCardView.gd` 代码硬编码,信息密度高但缺少"用法示例";帮助面板是一整页静态文本;没有首次进入引导;状态栏、失败提示和关卡选择页几乎没有面向新人的解释。
- 实现路径(按顺序执行):

  1. **卡牌说明数据化与"效果/条件/示例"三段式文案**
     - `data/rules.json` 全部 14 张牌追加 `desc`(一句话效果+触发条件)与 `tip`(具体使用示例/反制提示)。
     - `src/rules/RuleCard.gd` 增加 `desc: String`、`tip: String` 并在 `from_dict()` 解析;`GameManager._default_rules()` 同步补降级文案。
     - `src/ui/RuleCardView.gd`(T3.5 完成后)卡面显示三段式:①类型+元素图标 ②"触发 X 接触 Y → 结果" ③`desc`;悬停 tooltip 显示 `tip` 与半径/寿命/连锁奖励。
     - 文案规范: 一句话说明触发条件、结果元素、是否消耗接触物;`tip` 必须包含一个可执行示例(如 蒸汽化:"把柱子放在水与熔岩都覆盖到的空格上,水→汽、熔岩→岩")。
     - 验收用例: 新增 TC-31a —— 遍历 rules.json:14 张牌 `desc/tip` 非空、长度 ≤ 80 字、无 U+FFFD、卡牌 id 与 `desc` 一一对应。

  2. **帮助界面改版为分页手册**
     - 新建 `data/help.json`:6 个分页章节,每页含 `title`、`summary`(一句话)、`body`(要点列表)、`example`(可执行示例):
       ① 目标与回合流程 ② 三种规则卡怎么读 ③ 元素与状态速查 ④ 催化剂尘与风 ⑤ 死寂/混沌与反制 ⑥ 操作与存档。
     - `scenes/Main.tscn` 的 HelpPanel 改为"上一页/下一页 + 章节标题 + RichTextLabel"结构,`scenes/Main.gd` 增加 `_help_page` 状态与翻页逻辑;正文用 14-16px 行高 1.4 倍排版。
     - 关键词首次出现时加粗,并在文末附"名词对照表"(规则柱/连锁/催化剂尘/死寂/混沌)。
     - 验收用例: 新增 TC-31b —— 6 页均可翻页、每页含 `title/summary/example` 关键词、文本渲染高度不超过面板(复用 TC-23a 的 shaped text 测量)。

  3. **首次进入引导层**
     - `src/world/SaveManager.gd` meta 区增加 `onboarding_seen`(与 unlocked 同级持久化,删档不丢);新增 `is_onboarding_seen()` / `set_onboarding_seen()`。
     - `scenes/Main.gd` 在"首次进入关卡且未完成引导"时显示引导遮罩,5 步:① 从手牌选一张牌 ② 把柱子放到网格(高亮手牌区与网格区) ③ 点击"执行演化" ④ 看懂演化结算与回合推进 ⑤ 点击"?"可随时查帮助、主菜单可返回;每步允许"下一步/跳过"。
     - 引导层只高亮并锁定对应控件,不修改游戏状态;测试注入 `FORCE_ONBOARDING=1`(或 GameManager 调试开关)可重复触发。
     - 验收用例: 新增 TC-31c —— 引导步骤数=5、按顺序推进、跳过/完成后 meta 持久化、强制开关可重新进入、引导期间误点不改变网格/能量/手牌。

  4. **其他新玩家易用性提升**
     - `scenes/Main.gd` 的 StatusLabel 按 phase 显示下一步提示: 布局="选择手牌后点击网格落柱(最多 3 能量)"、演化="演化中…"、结算后="下一回合:抽牌并回满能量"。
     - `GridRenderer._draw_legend()` 选中手牌时高亮该牌的 trigger/contact 元素,并在地图格上给 trigger 元素加描边。
     - 不可操作按钮给出原因 tooltip: 能量不足/手牌为空/未落柱时,ExecuteButton tooltip 显示"先落柱才能执行"。
     - `src/ui/LevelSelect.gd` 每关按钮下加规则预览 chips(第2关: 孢子+燃烧;第3关: 冰+雪;第4关: 祝福+天灾)。
     - `GameManager.chaos_check()` / `game_over` 失败文案追加反制提示(水失控 → "使用「干涸」清除水;或在水过半前消耗它")。
     - 所有新增中文文案使用 UTF-8,禁止 U+FFFD(沿用 TC-04 检查思路)。
