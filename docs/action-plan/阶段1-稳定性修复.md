## T1.4 存档系统:三槽位 + 命名 + 覆盖确认 + 秒级时间戳(TC-13 系列)

- 优先级: P0 · 预估: 8h · 状态: [ ] 待开始 · 依赖: 无
- 需求(用户补充规格,替代原"仅解锁进度持久化"方案):
  1. **三个存档槽**:存档分两层——meta 区存全局通关进度(`unlocked`,删档不丢),槽位区存单局快照(网格/柱/手牌/能量/回合/连锁/风/关卡)。
  2. **任意一次演化结束后可存档**:`execute()` 结算完成后启用"存档"入口 → 选择槽位(3 选 1)+ 输入存档名。
  3. **覆盖规则**:目标槽非空时弹确认框"将覆盖「槽名」(最后存档 <时间>),确定?";若本局就是从该槽加载的(记录 `loaded_from_slot` 标记),再存同槽**不再提示**;覆盖成功后标记更新为当前槽。
  4. **开始游戏必须选档或开新游戏**:新增启动入口 `scenes/SaveSelect.tscn`(`project.godot` 的 `main_scene` 改指它),列出 3 槽(名称 + 最后存档时间,空槽显示"空槽位")+「新游戏」按钮(进入关卡选择)+「调整存档」按钮。
  5. **主界面"调整存档"按钮**:每个槽可重命名、可删除(删除需确认);删除本局来源槽后 `loaded_from_slot` 置 -1(之后存任意槽都提示覆盖确认)。
  6. **时间显示精确到秒**:`Time.get_datetime_string_from_unix_time(t, false, false)` 输出 `YYYY-MM-DD HH:MM:SS`,槽位列表与覆盖确认框均显示。
- 改动点:
  1. 新建 `src/world/SaveManager.gd`:槽位读写(`user://save.cfg` 或 `user://saves/*.json`)、全局 `unlocked`、快照序列化/反序列化(Grid 元素+状态+`placed_at_turn`、pillars、turn/chain_total/dead_turns/energy/hand/wind/level)、`loaded_from_slot` 标记、覆盖确认回调(可注入,便于测试)。

  3. 新场景 `scenes/SaveSelect.tscn` + `src/ui/SaveSelect.gd`(选档/新游戏/调整存档);`scenes/Main.gd` 加"存档"按钮与存盘弹窗(选槽 + 命名 + 覆盖确认);`project.godot` main_scene 改指 SaveSelect;`LevelSelect` 保留为"新游戏"入口。
