# 催化剂 (Catalyst)

> 回合制网格策略游戏:在元素网格上放置"规则柱",启动元素连锁反应,累计连锁总数达成关卡目标。
> 玩家不是战士,而是**规则的编织者**——看着自己规划的连锁如"连绵雨"般滚雪球。

**引擎**:Godot 4.x(开发环境 4.7)· **语言**:GDScript
**当前阶段**:第四阶段完成 —— 4 大关卡全部可玩(海岸 / 丛林 / 高山 / 火山口),含孢子、冰晶、祝福与天灾机制。

## 快速开始

1. 用 Godot 4.x 打开 `project.godot`,按 **F5** 运行。
2. 入口场景为 `scenes/SaveSelect.tscn`(存档选择):**选择一个存档继续 / 开始新游戏 / 调整存档**;"新游戏"进入关卡选择 `scenes/LevelSelect.tscn`。
3. 启动时自动运行核心自检(`tests/run_tests.gd`,30 条),控制台输出 `[CatalystTests] ALL PASS`;失败会在控制台报错。

命令行运行白盒测试(无需窗口):

```powershell
godot --headless --path <项目根目录> --script res://tests/whitebox_tests.gd
# 只跑某个用例:
godot --headless --path <项目根目录> --script res://tests/whitebox_tests.gd -- --filter=TC-06
```

## 操作说明

| 操作 | 效果 |
|------|------|
| 左键手牌 | 选中规则牌(网格上出现落柱范围预览) |
| 左键网格 | 放置规则柱(消耗 1 能量) |
| 右键规则柱 | 撤回(退还能量与卡牌) |
| 执行演化 | 结算本回合所有规则柱的连锁反应 |
| 4x加速 / 跳过 | 演化阶段加速或立即结算 |
| 存档 | 布局阶段弹出存档面板:命名 + 选槽(3 槽);覆盖非来源槽需确认 |
| `?` 按钮 | 帮助面板 |
| 主菜单 | 返回关卡选择 |

每回合:抽 3 张牌、能量回满至 3,**手牌上限 8**(超限抽牌进弃牌堆)。规则柱存活 4 回合,左上角数字为剩余回合。

### 存档系统

- 三个存档槽,槽位显示名称与最后存档时间(精确到秒 `YYYY-MM-DD HH:MM:SS`)。
- 游戏内任意演化结束后可命名存档;覆盖已有存档时弹确认框,**从该存档加载的本局再存同槽不再提示**。
- 主界面"调整存档"按钮:重命名 / 删除(需确认);全局通关进度(关卡解锁)独立持久化,删档不丢。

## 玩法与规则

### 回合流程

**布局** →(放牌落柱)→ **执行演化**(连锁结算)→ 世界演化(衰减/生成/风/天灾)→ 回到布局。

### 三种规则类型

- **转化 TRANSFORM**:触发格元素 → 结果元素,并替换范围内首个接触元素(可设置 `self_replace`)。
- **增殖 MULTIPLY**:触发格保留,其 4 邻空格 → 结果元素。
- **灭绝 EXTINCTION**:半径内触发元素(可加 `also_count`)≥ 阈值 → 全部清空,并清 `also_clear` 元素。

连锁循环:执行全部 Reaction → 记录受影响格 → 只重查受影响格触及的柱子 → 直到无新反应(上限 1000,快照去重防振荡)。

### 规则卡牌(14 张,`data/rules.json`)

| 牌 | 类型 | 效果 | 出现关卡 |
|----|------|------|----------|
| 蒸汽化 | 转化 | 水触熔 → 汽,熔 → 岩 | 全部(牌池 ×3) |
| 加速生长 | 增殖 | 植触汽 → 空格扩散植 | 全部(牌池 ×3) |
| 丛林灭绝 | 灭绝 | 半径内植+草 ≥5 → 清空植草,也清汽 | 全部 |
| 干涸 | 灭绝 | 半径内水 ≥5 → 清空水,也清草 | 全部 |
| 岩化 | 转化 | 岩触植 → 土 | 全部 |
| 草生 | 增殖 | 土触植 → 空格生草 | 全部 |
| 采掘 | 转化 | 植触矿 → 两者消失,**+5 连锁** | 全部 |
| 草殖 | 增殖 | 草触草 → 空格扩散草 | 全部 |
| 结孢子 | 增殖 | 汽触植 → 空格生孢 | 第 2 关 |
| 孢子萌发 | 增殖 | 水触孢 → 空格生植 | 第 2 关 |
| 结冰 | 增殖 | 冰触冰 → 空格扩散冰 | 第 3 关 |
| 融冰 | 转化 | 冰触汽 → 水,汽消耗 | 第 3 关 |
| 祝福 | 转化 | 汽触植 → 空,该格 +祝福(3 回合,反应连锁 ×2) | 第 4 关 |
| 陨石术 | 灭绝 | 半径内熔 ≥3 → 清空熔,也清植 | 第 4 关 |

所有牌默认 `radius=2`(曼哈顿距离)、`life=4` 回合。

### 世界规则(每回合结束自动执行)

| 规则 | 说明 |
|------|------|
| 蒸汽消散 | 汽放置 2 回合后消失 |
| 草枯萎 | 草连续 2 回合无邻植/草 → 变土 |
| 土壤成岩 | 土放置 2 回合后 → 岩 |
| 元素生成 | 每回合随机 1-2 个空格 → 水/岩 |
| 燃烧 | 植邻熔岩 → 点燃(BURNING);蔓延相邻植;燃尽 → 空 |
| 孢子漂移 | 孢随风向移动 1 格,越界消失 |
| 降雪 | 随机 1-2 格 +覆雪(SNOW,2 回合) |
| 雪凝冰 | 覆雪 + 水 → 冰 |
| 雪消融 | 覆雪邻熔/汽 → 消散 |
| 天灾(第 4 关,30%/回合) | 陨石:随机格 → 熔 + 陨石熔岩(衰减后变岩)/ 地震:随机 2 格清空 / 火山喷发:空格 → 熔 |

### 催化剂尘与风

- 演化中**每累计 5 连锁**向随机 3 格播撒催化剂尘(持续 5 回合)。
- 尘 4 连通成团块;团块触及规则柱扫描范围 → 扩展该柱的判定范围(可隔空找到接触元素)。
- 风:每回合随机风向(4 向)+ 风速(1-3);推动陈尘(剩余 1 回合的尘,新尘落地保护)与孢子,越界消失。

### 胜利与失败

- **胜利**:累计连锁 ≥ 关卡目标 → 解锁下一关。
- **失败**:连续 10 回合 0 连锁("死寂");或单一元素超过全场 50% 且无对应灭绝柱("混沌失控")。


## 数据驱动扩展

架构原则:**引擎代码不动,新元素/牌/关卡只加数据与枚举值**。

- **加新牌**:`data/rules.json` 追加条目(`level=0` 全关通用,`level=N` 仅第 N 关出现);新元素/状态需在 `src/core/Element.gd` / `State.gd` 加枚举 + `GridRenderer` 配颜色/贴图。
- **加关卡**:新建 `data/levels/*.json` + 在 `src/world/LevelManager.gd` 的 `LEVELS` 注册;新机制放入 `GameManager._world_rules()`。
- **改规则/引擎**:在 `tests/run_tests.gd` 同步补测试。
